## 1. Reddit: r/chrome_extensions (primeiro, é o mais tolerante com projeto novo)

**Título:** I made a free Chrome extension that saves Google Meet captions as Markdown files on your computer

**Texto:**
I built Talktrail because I wanted Meet transcripts that stay on my machine instead of going through yet another cloud service.

What it does:
- Reads the captions Google Meet already shows and saves each meeting as a `.md` file (title, date, duration, who spoke and when).
- Live text in a side panel next to the call, plus notes and a per-meeting agenda.
- Agendas are also plain files, so an AI tool can edit them and the change shows up in the extension.
- No account, no cloud, no telemetry. Free.

Limits, so you know before installing: it only works with Google Meet, and the quality is whatever Meet's captions give you. It does not summarize anything by itself; the Markdown file is meant to be handed to the AI you already use. The interface is in English and Portuguese, and it finds Meet's captions by icon, so Meet can be in any language.

Chrome Web Store: https://chromewebstore.google.com/detail/talktrail/jneejlpdlldinjnilghnndennbnpbeak
Source (MIT): https://github.com/lavinialencar/talktrail

I'm the developer. Feedback and bug reports are very welcome, especially from people using Meet in a language other than English or Portuguese.
