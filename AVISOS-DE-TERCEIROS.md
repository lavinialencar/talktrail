# Componentes de terceiros

O Talktrail inclui, em `extension/vendor/`, os componentes abaixo, sem alteração de código. As fontes de `store/src/fonts/` servem só para gerar a arte da loja.

| Componente | Arquivo | Licença |
|---|---|---|
| GSAP 3.13.0 (GreenSock) | `gsap.min.js` | Licença padrão gratuita do GSAP, https://gsap.com/standard-license |
| CodeMirror 6 (editor de notas) | `editor.js` | MIT, https://github.com/codemirror |
| Inter (fonte) | `fonts/inter-*.woff2` | SIL Open Font License 1.1, https://rsms.me/inter |
| Archivo (arte da loja) | `store/src/fonts/Archivo-*.woff2` | SIL Open Font License 1.1, https://github.com/Omnibus-Type/Archivo |
| IBM Plex Sans e Mono (arte da loja) | `store/src/fonts/IBMPlex*.woff2` | SIL Open Font License 1.1, https://github.com/IBM/plex |
